# Security Policy

## Supported Versions

The `main` branch and the latest tagged release receive security fixes.

## Reporting a Vulnerability

Email security disclosures to `security@example.com` with:

- affected version or commit
- reproduction steps
- impact assessment
- any suggested mitigation

Do not open public issues for suspected vulnerabilities.

## Secrets

Never commit real credentials, API keys, private keys, or production `.env`
files. Use `.env.example` for placeholders only.
